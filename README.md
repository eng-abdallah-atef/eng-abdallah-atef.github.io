# Eng. Abdallah Atef · Portfolio

Live: https://eng-abdallah-atef.github.io/  ·  Arabic: https://eng-abdallah-atef.github.io/?lang=ar

- `index.html` – the whole site (bilingual EN/AR, dark theme with light beige sections, Cairo font).
- `img/` – photos. Each photo has a 4K master (`name.jpg`, 3840 px long edge) plus `name-800.webp` and `name-1600.webp`; the browser picks the right size automatically.
- `og.jpg` – 1200×630 preview shown when the link is shared on WhatsApp/LinkedIn.
- To replace a photo, replace all three files with the same names.
